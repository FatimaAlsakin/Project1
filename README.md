# Wordle 

## Technologies Used 
1. HTML
2. CSS
3. JavaScript 

## Description 
Players have six attempts to guess a five-letter word, receiving feedback through colored tiles that indicate correct letters and their placement.

## User Stories 
1. As a user, I want to type 5 letter word
2. As a user, I want to check if my gussed word is correct 
3. As a user, I want the letter tile to change color
4. As a user, I want to want an on-screan keyboard that update letter color and shows how many trys I have left
5. As a user, I want to see if I win or lost
